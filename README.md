# Simple API Java

API Application simples em Java 21 com Spring Boot, Spring Data JPA, Spring Security e Docker.

## requirements

- Java 21
- Git
- Docker

## Build and run

```sh
docker compose up --build
```

## Unit tests (validation)

./mvnw test


## Online Docs (OpenAPI)

http://localhost:8080/swagger-ui/index.html
